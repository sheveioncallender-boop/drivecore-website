# DriveCore Automotive Website — Odoo 19

A complete dark automotive website module for DriveCore Auto Import & Solutions Limited, built with reusable QWeb templates, a global custom header and footer, direct-loaded assets, responsive layouts, and authentic workshop photography.

## Public pages

- Home (`/`)
- About Us (`/about-us`)
- Services (`/services`)
- Six service-detail routes
- Book a Service (`/book-a-service`)
- FAQ (`/faq`)
- Contact Us (`/contact-us`)
- Privacy Policy
- Terms and Conditions
- Request confirmation

## Installation / upgrade

1. Replace the existing `drivecore_website` module folder with this version.
2. Commit, push, and redeploy the repository.
3. Update the Odoo Apps list.
4. Upgrade **DriveCore Automotive Website**.
5. Open the root domain in a private window or hard-refresh with `Ctrl + Shift + R`.

Version 19.0.2.2.0 overrides Odoo's website root controller and renders the DriveCore homepage directly at `/`. It also resets the website homepage URL to `/`, updates the website favicon, and retires the temporary homepage route from earlier builds.


Version 19.0.2.2.0 also enforces white headings with green emphasis and refreshes the browser favicon with the DriveCore DC emblem.
