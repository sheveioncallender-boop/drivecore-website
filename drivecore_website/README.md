# DriveCore Automotive Website — Odoo 19

Complete multi-page website module for **DriveCore Auto Import & Solutions Limited**.

## Included

- Premium responsive homepage
- About Us
- Services overview
- Six individual service routes
- Book a Service form
- FAQ
- Contact Us form and map
- Privacy Policy
- Terms and Conditions
- Request-received page
- Global DriveCore header and footer
- Responsive mobile burger menu
- DriveCore favicon and touch icon
- Backend menus for service and contact requests
- Direct-loaded CSS and JavaScript for Cloudpepper reliability

## Installation

1. Upload the `drivecore_website` folder to the custom addons repository.
2. Commit and deploy the change to Cloudpepper.
3. Restart/update the Odoo service if required by the environment.
4. In Odoo, enable developer mode and update the Apps list.
5. Search for **DriveCore Automotive Website** and install it.
6. Open the Website app and confirm DriveCore is the intended active website.
7. Clear the browser cache after installation or an upgrade.
